# PM.bi CRM roadmap

Цель: полноценная CRM для строительной компании, где центральная сущность — объект строительства.

## Текущая техническая договорённость

Рабочая архитектура теперь:

- `backend/` — Python backend, авторизация, роли, API, SQLite;
- `frontend/templates/` — общие шаблоны, layout, login;
- `frontend/pages/` — маленькие страницы разделов;
- `frontend/assets/` — общие CSS, JS, logo.

Старая сохранённая HTML-копия `deploy/copy` удалена из рабочей версии, потому что весила около 679 МБ и дублировала хедер/сайдбар/стили в каждой странице.

## Что нужно реализовать

1. Полноценная CRM с карточками клиентов.
2. Ведение объектов строительства.
3. Полная карточка объекта:
   - заказчик;
   - адрес;
   - ответственные;
   - этапы работ;
   - сроки;
   - бюджет;
   - финансы;
   - задачи;
   - документы;
   - материалы;
   - история коммуникаций.
4. График производства работ.
5. Генерация актов выполненных работ.
6. Финансы по объекту.
7. Управленческая отчётность.
8. Кредитный модуль.
9. AI-помощник:
   - планирование графика производства работ;
   - анализ объекта;
   - анализ финансов;
   - выявление рисков;
   - рекомендации по срокам, бюджету, задачам и снабжению.

## Основная логика продукта

Сделка приводит к объекту. Объект становится центром работы.

Внутри объекта должны жить:

- график работ;
- задачи;
- документы;
- акты;
- финансы;
- закупки;
- склад;
- чаты;
- подрядчики;
- отчёты;
- AI-анализ.

## Очередь реализации

1. Объекты / проекты.
2. Смета и материалы: нужно / куплено / использовано / остаток / нехватка.
3. Склад и поступления.
4. График производства работ.
5. Пользователи и роли.
6. Ограниченный кабинет заказчика.
7. Закупщик: заявки, поставки, склад без лишней прибыльности.
8. Сделки и связь сделки с объектом.
9. Задачи по объектам.
10. Документы и акты выполненных работ.
11. Финансы по объекту.
12. Чаты по объектам.
13. Отчётность.
14. Кредитный модуль.
15. AI-помощник по объекту.

## Уже сделано

- backend-авторизация;
- роли: директор, прораб, закупщик, заказчик;
- серверные сессии через HttpOnly cookie;
- SQLite база;
- новый лёгкий frontend layout;
- страницы: объекты, склад, график, чаты, пользователи, отчётность;
- API проектов;
- API сводки материалов;
- расчёт нехватки материалов по смете.
- API этапов графика производства работ;
- API задач по объекту;
- API документов с ограничением видимости для заказчика;
- API чатов: внутренний чат команды и чат с заказчиком;
- API складских операций: закупка, поступление, использование, списание;
- API импорта сметы от внешнего бота/сканера;
- API анализа объекта: прогресс, нехватки, риски, рекомендуемые действия;
- API создания объекта с автоматическим созданием этапов, документов и чатов;
- API dashboard для директорской отчётности;
- frontend-вкладки объекта: обзор, материалы, график, задачи, документы, чат, AI-анализ;
- отдельные живые страницы: склад, график работ, чаты, пользователи;
- живая директорская отчётность;
- форма создания объекта;
- UI-ограничения меню и вкладок по ролям;
- компактный интерфейс CRM: меньше шапка, сайдбар, карточки, формы и списки;
- быстрый блок “Что горит” на объектах по критичным нехваткам из dashboard API;
- улучшенный визуальный стиль: sidebar с иконками, risk-подсветка карточек, аккуратнее KPI/табсы/строки;
- быстрые действия внутри карточки объекта: склад, график, чаты, отчётность;
- обновлённая цветовая палитра: тёплый фон, зелёно-синие акценты, меньше серого;
- явное разделение секций: KPI, списки, формы и критичные блоки визуально отделены;
- уменьшены скругления, интерфейс стал строже и ближе к B2B/ERP.
