# Reference materials

Сюда кладём старую CRM/сохранённые HTML-выгрузки только как донор интерфейса и логики.

Рабочий frontend находится в:

```text
frontend/
```

Старую CRM-копию лучше положить сюда:

```text
reference/legacy-crm/
```

Она не должна быть основной рабочей архитектурой, потому что старая saveweb-копия весит сотни мегабайт и содержит повторяющиеся хедеры, сайдбары и стили в каждой странице.

Как использовать:

1. Смотрим нужный старый раздел.
2. Берём смысл, таблицы, поля, расположение блоков.
3. Переносим в маленькую страницу `frontend/pages/*.html`.
4. Данные подключаем через backend API.
