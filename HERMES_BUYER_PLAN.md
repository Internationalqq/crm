# Закупщик Автобота через Hermes API — 25 сентября 2026

Baseline CRM `4d874e4`, AutoBot `beafe8e`. Tracked CRM clean. AutoBot имеет чужое изменение `data/search_resume_checkpoint.json`, сохраняем его; `.agents/`, `.codex/`, `.impeccable/` не трогаем.

Пользователь подтвердил Hermes через API и управление с сайта. Выбран Mac как исполнитель: там уже настроены агенты и каналы; сервер Автобота должен хранить задания и результаты, Mac забирать их исходящим HTTPS-соединением. Найден сетевой адрес из RustDesk, SSH отвечает, но вход egor отклоняется. Наличие работающего Hermes API пока не установлено. Открытый чат не доказывает работоспособность каналов.

Первый проверяемый пакет: отдельный профиль autobot-buyer, HTTP-адаптер, структурированный запрос по нескольким позициям материалов/работ/оборудования одного направления, подготовка черновика и проверка результата. У каждого задания есть идентификатор; повтор и таймаут не запускают второй независимый запрос. Черновики не публикуются как цены и не изменяют покрытие сметы. Исходные позиции, количества/единицы, регион, точка доставки и неизвестные условия сохраняются. Браузерный поиск и действующие агенты не меняются.

Первый профиль не имеет инструментов отправки; на стороне API перед запуском проверяется набор инструментов. Отправка продавцам, звонки, запись разговоров и изменение внешних аккаунтов в этот пакет не входят. Следующие пакеты: разрешённая отправка выбранным адресатам с подтверждением результата, корреляция ответов с заявками, извлечение условий/КП, затем голос.

Проверки: подставной Hermes HTTP API без сети и реальных адресатов, проверка авторизации/ошибок/таймаутов/повторов/неполного ответа/несовпавших позиций; CLI-прогон на синтетическом наборе и отдельный connectivity-check реального профиля после доступного адреса. Секреты только env/приватный файл, не в ответах/артефактах. Рабочие БД не мигрируем; сначала автономный адаптер и профиль, подключение боевого экземпляра после выбора размещения и проверки совместимости установленной версии.

Основания: https://hermes-agent.nousresearch.com/docs/user-guide/features/api-server ; https://hermes-agent.nousresearch.com/docs/user-guide/profiles . Документация актуального Hermes не доказывает наличие этих API на Mac.

## Выполнено в первом пакете

В AutoBot добавлены `autobot/hermes_buyer.py`, `tests/test_hermes_buyer.py` и
`HERMES_BUYER.md`: отдельный HTTP-клиент, снимок требований и SQLite-журнал
черновиков. Проверяются отключённые инструменты, точный состав позиций,
идентификатор запуска и адрес профиля. Повторное создание одного снимка
возвращает существующее задание. После неоднозначного POST повтор блокируется;
известный run_id читается после перезапуска. Это консервативная защита, пока
не доказана поддержка идемпотентности установленным Hermes.

19 целевых unittest прошли на изолированной копии, включая локальный HTTP
round-trip и восстановление журнала. Начальный Python не имел requests;
успешный запуск выполнен установленным Python 3.11 с зависимостью. Проверки
общей CRM/AutoBot, UI, production и живого Hermes не выполнялись. Код не
импортируется веб-приложением: пользовательского запуска на сайте пока нет.
Рабочие БД и существующий поиск не менялись; миграции не нужны.

Следующие пакеты: (1) живой синтетический тест отдельного профиля на Mac;
(2) серверная очередь и исходящий poller с lease/heartbeat/подтверждением;
(3) запуск и статусы в тендере/загруженной смете; (4) поиск поставщиков по
направлениям; (5) согласование и отправка выбранным адресатам; (6) приём ответов
и проверка цен. Это открытые задачи, не завершённая интеграция.

Для доступного агента на Mac подготовлен `HERMES_MAC_HANDOFF.md`. Требуется
настройка доступа/профиля; пароли и токены в чат передавать не нужно.
