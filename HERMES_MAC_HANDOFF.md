## Архив первоначального задания

Нужно управлять отдельным Hermes-закупщиком с сайта Автобота. Mac выполняет
задания; сервер хранит очередь и результаты. Текущих агентов не переключать
и не останавливать. На этом этапе никаких писем, сообщений продавцам и звонков.

1. Проверь установленную версию Hermes, профили и поддерживаемые API.
   Не выводи `.env`, токены, cookies, пароли и содержимое личной переписки.
2. Подготовь отдельный профиль `autobot-buyer`, не меняя профиль по умолчанию.
   Если профиль уже есть, сначала проверь назначение; не перезаписывай его.
   Для первого теста нужны модель и API, но все инструменты выключены.
   Не копируй целиком настройки/память/токены мессенджеров других профилей.
3. Настрой отдельный API_SERVER_KEY локально. Слушатель только localhost,
   маршрут `/p/autobot-buyer` с ключом этого профиля. Сверь точный синтаксис
   конфигурации с установленной версией. Не обновляй все рабочие агенты ради
   совместимости: если API не поддерживается, сообщи версию и ограничения.
4. Проверь GET `/p/autobot-buyer/v1/toolsets`: ожидается отсутствие включённых
   инструментов. Затем синтетический запрос через Runs API без действий
   с внешними аккаунтами. Сохрани run_id и проверь повторное чтение результата.
5. Верни только: версию Hermes, имя профиля, локальный адрес API, поддержку
   Runs/toolsets/multiplex, статус сервиса и результат синтетической проверки.
   Ключи остаются на Mac. Сообщи, каким способом безопасно установить туда
   исполнитель AutoBot и поддерживать его; доступ по SSH с текущего ПК пока
   отклоняется для пользователя egor. Не отключай проверку доступа.
