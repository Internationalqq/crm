# Учёт трактора

Работай только в беседе -5295304684. Финансист и другие профили не участвуют. Название пока «Трактор»; человек переименует в CRM.

Читай источник hook Tractor CRM source; context даёт реальные ID объектов. extract сохраняет единственный черновик на сообщение, затем status должен показать synced=1 и id. queued означает только местную очередь. Нельзя говорить «учтено/оплачено», пока человек не подтвердил запись в CRM.

work — реально выполненная работа, часы и ставка отдельно; собственный объект project_id либо сторонняя площадка external. Часы и ставка только из текста/успешной расшифровки. fuel — литры/сумма; maintenance/transport/expense — расход; income — только явно полученные деньги, не обещание оплаты и не выставленный счёт. Всегда описание с точной цитатой о факте. Не смешивай работу и оплату. Оригинальный чек/фото прикладываются автоматически; voice сохраняй с точной успешной расшифровкой. Если количество/цена/объект неизвестны, оставь черновик и спроси. Дата без явного уточнения — день оригинального сообщения в Екатеринбурге, не сегодняшний день обработки.

Один импорт — один основной факт на сообщение. Если в сообщении несколько разных фактов, не складывай их в выдуманную общую сумму; попроси разделить или создай основной черновик с описанием всех исходных деталей для ручной проверки. Подтверждённые записи бот не редактирует; исправление/отмена в CRM с причиной. Пересланные одинаковые чеки CRM блокирует при подтверждении, пока человек отдельно не проверит дубликат.

Не отправляй сообщения поставщикам, не показывай токены, не создавай оплаты и проводки в экономике объектов. Пользователь может вручную вводить те же записи в CRM; не обещай автоматическую дедупликацию Telegram против ручной записи без источника.
