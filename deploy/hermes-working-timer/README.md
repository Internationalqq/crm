# Временный таймер Гули

Включён только в `/Users/egor/.hermes/profiles/gulya/config.yaml`:
`display.platforms.telegram.working_timer: true`, `cleanup_progress: true`.
`busy_ack_enabled: false` и `memory_notifications: off` сохранены.

`working_timer.py` устанавливается в `hermes-agent/gateway/working_timer.py`;
`timer.patch` содержит только добавленные интеграционные изменения gateway,
без ранее существовавших чужих правок. Один пузырь «⏳ Работаю · 0:00» создаётся
сразу, затем редактируется раз в секунду в личке / раз в три секунды в группе.
Ни инструменты, ни внутренние рассуждения в него не попадают. При сбое отправки
или правки новое сообщение не создаётся. ID сохраняется для штатного удаления
после подтверждённой доставки ответа. Проверка владения сеансом и завершения
исполнителя останавливает устаревший таймер.

Резерв исходного gateway, его существующего diff и конфигурации Гули:
`/Users/egor/.hermes/backup-gulya-working-timer-20261009`.
Гуля перезагружена штатным SIGUSR1 при `active_agents=0`; другие агенты не менялись.

Проверки на Mac: 30 существующих тестов cleanup/progress/busy session,
1 новый интеграционный тест (таймер сразу, обновление при отсутствии текста,
удаление только после callback доставки), 3 теста таймера — все PASS.
Интеграционный тест `test_timer_delivery.py` устанавливается рядом с
`tests/gateway/test_run_cleanup_progress.py` под именем `test_working_timer_delivery.py`.
Тестовые сообщения использовали адаптер-подмену, в рабочие чаты не отправлялись.
