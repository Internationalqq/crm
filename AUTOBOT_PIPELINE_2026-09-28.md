# AutoBot: единая цепочка позиции и предложения — 28 сентября 2026

## Исходное состояние и поручение

Пользователь поручил реализовать связь «строка сметы → подходящий товар →
сопоставимая цена → проверенный контакт → обращение → ответ» и сделать
существующий интерфейс понятнее. Визуальное направление: компактный рабочий
AutoBot, существующие цвета и чаты, без копирования перегруженной карточки
конкурента. Это расширение действующего интерфейса, не замена бренда.

Baseline CRM `06ed608`, AutoBot `b6fa1f7`. Отслеживаемый CRM diff пуст;
AutoBot содержит прежнее изменение `data/search_resume_checkpoint.json`.
Неотслеживаемые настройки, артефакты и checkpoint сохраняются.

## Наблюдаемый результат

В тендере видно, по каким текущим строкам найдены варианты, какие цены
пригодны для сравнения, есть ли контакт, подтверждена ли отправка и получен
ли ответ с подходящей ценой. Ответ без цены и письмо в очереди не повышают
подтверждённое покрытие. Устаревший запрос не закрывает изменённую строку.
Пользователь открывает доказательство/переписку и может продолжить поиск
конкретной позиции. Сметные суммы и существующий расчёт рынка сохраняются.

## Пакеты

1. Серверная проекция по текущей смете и существующим источникам, подборам,
   очереди и ответам. Аддитивный защищённый GET API, без миграции рабочих БД.
   Различить опубликованную цену, пригодность сравнения и ответ поставщика.
2. Консервативное подтверждение точного товара из текстового ответа скриптом:
   полное наименование и характеристики в собственной строке ответа,
   единица/НДС/валюта, отсутствие замен и неоднозначности. Дополнительная
   проверка на сервере; неподтверждённые случаи остаются на уточнении.
3. Компактная сводка цепочки и фильтруемый список позиций со ссылками на
   источники и чаты. Сохранить историю, отправку своего сообщения, выбор
   позиций, фильтры и восстановление страницы.
4. Изолированные проверки логики и UI, размеры 390/768/1280, проверка diff,
   commit/push, кандидат Linux и выпуск с резервом/контролем данных.

## Проверки

Сценарии: сайт без цены; неправильный размер/единица; точное предложение;
расчётная строка; известный контакт без отправки; queued/uncertain/sent;
ответ с вопросом; частичный ответ; цена за масштабированную единицу;
повторное получение ответа; изменение сметы; другой тендер/нет доступа;
неработающий почтовый сервис. Существующие buyer/market/frontend проверки
запускать по затронутому участку, результаты фиксировать отдельно.

### Реализовано

- Защищённый GET `/api/tenders/<tid>/buyer/pipeline` читает текущую смету,
  результаты поиска, выбранные черновики, отправки и ответы. Шесть независимых
  признаков: варианты, сопоставимая цена, контакт, отправка, ответ, точная цена
  из ответа. Проверяются версия потребности, регион, характеристики, объём и
  выбранная часть группового запроса; старые запросы не закрывают новую строку.
- Проекция читает обе очереди через SQLite `mode=ro`, без миграции и ограничения
  на последние 250 черновиков. Контакт кампании относится только к позициям
  выбранного сообщения. Текущие статусы и исторические факты разделены:
  уточнение после ответа возвращает строку в ожидание, сохраняя факт ответа.
- Сервер повторно проверяет точное наименование, характеристики, единственную
  явную цену за единицу, валюту и НДС в собственном тексте поставщика. Подмена
  размера, цитата нашего письма, номер строки, количество, цена «от», замена
  товара или неоднозначная цена остаются на проверке. Поздняя неоднозначная
  цена не позволяет показывать прежнее предложение поставщика как актуальное.
- Во вкладке «Поставщики» появились шесть компактных фильтров, список позиций,
  причины состояний, время, предложения и контакты с источниками, переход в
  конкретную переписку и подбор поставщика по одной строке. Список по умолчанию
  свёрнут; история, ручное сообщение, существующие фильтры и вкладки сохранены.
- Подпись общей шапки уточнена: «С ценой для сравнения». Наличие цены на сайте
  не объявляется ответом поставщика. Почтовый статус берётся из публичного
  heartbeat, секретная конфигурация в ответ не попадает.

### Контрольные данные и внешняя граница

На текущей «Волге»: 259 строк, из них 213 для закупки и 46 вне подбора;
186 с вариантами, 28 с сопоставимой ценой, 2 с контактами, по 2 подтверждена
отправка, по 1 был ответ, 0 с проверенной ценой из ответа. Счётчики относятся
к позициям, не к количеству отправленных писем. После ответа с вопросом об
адресе отправлено уточнение, поэтому текущий статус снова «Ожидаем ответ».

не устанавливает соединение. Это проверка доступности без авторизации и без
отправки писем. Почтовый сервис в этом выпуске не запускался, Mac AutoBot
не включался. Автоматический разбор цены реализован, но реальная сквозная
отправка/получение через SMTP этим пакетом не подтверждена. Сметные суммы и
медиана основной таблицы не меняются; новые точные ответы видны в цепочке.
